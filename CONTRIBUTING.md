# Contributing

Contributions are accepted under the GNU Lesser General Public License, version 3. Sign off each
commit under the [Developer Certificate of Origin 1.1](https://developercertificate.org/)
(`git commit -s`) to confirm you have the right to submit it.

Never put a real SIN, business number, slip, CRA file or database copy in an issue, a pull request
or a test. Use made-up values.

Run the tests before opening a pull request; see the Development section of the README.
